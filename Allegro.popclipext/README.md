# Allegro

Search for the selected text on [Allegro.pl](https://allegro.pl/), Poland's largest online marketplace.

Select any text, click the Allegro icon, and the Allegro search results open in your browser.

- Line breaks and repeated spaces in the selection are collapsed into single spaces.
- Hold **⌥ Option** when clicking to wrap the query in quotes for an exact-phrase search.

## Privacy

The selected text is sent to allegro.pl as the search query when you click the action.
Nothing is sent anywhere else.
