# Ceneo

Compare prices for the selected text on [Ceneo.pl](https://www.ceneo.pl/), the Polish price
comparison site.

Select any text, click the Ceneo icon, and the Ceneo search results open in your browser.

- Line breaks and repeated spaces in the selection are collapsed into single spaces.
- Hold **⌥ Option** when clicking to wrap the query in quotes for an exact-phrase search.

## Privacy

The selected text is sent to ceneo.pl as the search query when you click the action.
Nothing is sent anywhere else.
