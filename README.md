# PopClip extensions for Polish shopping sites

[PopClip](https://www.popclip.app/) extensions that search for the selected text on Polish
shopping sites.

| Extension | Searches |
|---|---|
| [Allegro](Allegro.popclipext) | [allegro.pl](https://allegro.pl/) |
| [OLX](OLX.popclipext) | [olx.pl](https://www.olx.pl/) |
| [Ceneo](Ceneo.popclipext) | [ceneo.pl](https://www.ceneo.pl/) |

## Install

Install from the [PopClip Extensions Directory](https://www.popclip.app/extensions/), or clone
this repository and double-click a `.popclipext` folder.

## Privacy

Each extension sends only the selected text, and only to the site it searches, when you click it.
