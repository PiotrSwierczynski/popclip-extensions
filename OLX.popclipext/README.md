# OLX

Search for the selected text on [OLX.pl](https://www.olx.pl/), the Polish classifieds site.

Select any text, click the OLX icon, and the OLX search results open in your browser.

- Line breaks and repeated spaces in the selection are collapsed into single spaces.
- Hold **⌥ Option** when clicking to wrap the query in quotes for an exact-phrase search.

## Privacy

The selected text is sent to olx.pl as the search query when you click the action.
Nothing is sent anywhere else.
